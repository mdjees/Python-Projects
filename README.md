A notebook exploring Super Bowl-related data. Open the notebook to review the dataset, analysis steps, and outputs.

## How to Use

1. Clone or download this repository.
2. Open the `.ipynb` files in Jupyter Notebook, JupyterLab, or Google Colab.
3. Run the notebook cells in order.

```bash
git clone https://github.com/mdjees/Python-Projects.git
cd Python-Projects
```

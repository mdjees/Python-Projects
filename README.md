# Python & SQL Projects

A collection of Python notebooks and SQL analysis projects, including practice work and business-oriented data exploration.

## Projects

### SQL: Zepto Inventory & Pricing Analysis
A PostgreSQL project exploring product data quality, stock availability, discounts, product pricing, and inventory composition.

- [Project documentation](SQL-Projects/Zepto-Inventory-Analysis/README.md)
- [SQL queries](SQL-Projects/Zepto-Inventory-Analysis/zepto_analysis.sql)

The inventory-value calculation is explicitly labelled as an estimate of available inventory value, not realised sales revenue.

### Python: Super Bowl Analysis
**File:** [superbowl.ipynb](superbowl.ipynb)

A notebook exploring Super Bowl-related data. Review the notebook for the exact dataset, analysis steps, and findings.

### Python: Simple Calculator
**File:** [Simple_Calculator.ipynb](Simple_Calculator.ipynb)

A beginner project demonstrating basic calculator operations and Python programming fundamentals.

## How to use

Clone the repository and open notebooks in Jupyter Notebook, JupyterLab, or Google Colab. Run SQL scripts in a PostgreSQL environment after loading the relevant source dataset.

```bash
git clone https://github.com/mdjees/Python-Projects.git
cd Python-Projects
```

## Tools
Python, Jupyter Notebook, PostgreSQL, and SQL.

## Data and reproducibility
Each project should identify its dataset source, data dictionary, licence, and any transformations required to reproduce the analysis. Where those details are not yet documented, treat findings as exploratory rather than independently verified.
